## 三、本地运行方式

### 方式一：直接打开

1. 下载并解压完整项目文件夹，保留原有目录结构。
2. 使用现代 Chrome、Edge 或 Firefox 打开根目录的 `index.html`。
3. 入口会自动跳转到 `docs/index.html`；也可以直接打开该文件。
4. 点击门或人物进入主页，或点击右上角“跳过开场”。

此方式无需安装软件依赖。浏览器若限制本地文件的部分功能，可使用下面的本地 HTTP 服务方式。

### 方式二：通过本地 HTTP 服务运行

需要已安装 Python 3。在项目根目录打开终端，运行：

```sh
python -m http.server 5173 --bind 127.0.0.1
```

Windows 中如果 `python` 命令不可用，但已安装 Python 启动器，可使用：

```sh
py -3 -m http.server 5173 --bind 127.0.0.1
```

服务启动后，在浏览器访问：

```text
http://127.0.0.1:5173/docs/
```

按 `Ctrl+C` 停止服务。如果 5173 端口已被占用，可将命令和访问地址中的端口一同改为其他可用端口，例如 5174。

## 五、已实现的主要功能

| 功能 | 操作与效果 |
| --- | --- |
| 开门入场 | 点击门或人物，播放人物动作、开门和镜头推进动画后进入正文 |
| 跳过与重播 | 点击“跳过开场”直接阅读；点击“再来串门”重新播放入口动画 |
| 会话内入口记忆 | 使用 sessionStorage，在当前会话再次访问时直接进入正文 |
| 未来方向 Tab | 点击“考研深造 / 出国学习 / 直接工作”，切换对应思考和准备内容 |
| Tab 键盘操作 | 聚焦方向选项后，使用左右方向键切换，Home / End 跳到首项 / 末项 |
| 页面导航 | 点击导航定位到对应区域，并随滚动更新当前栏目高亮 |
| 文字海洋互动 | 鼠标移动时附近文字轻微避让，鱼群游动时带动局部文字变化 |
| 暂停与继续 | 点击页尾按钮，暂停或继续海洋动画 |
| 邮箱复制 | 点击“复制邮箱”复制地址并显示结果；受浏览器限制时提供降级处理与手动复制提示 |
| 页尾彩蛋 | 点击星形按钮，依次显示不同的文字提示 |
| 滚动显现 | 内容进入视口后逐渐显示，形成阅读层次 |
| 响应式适配 | 桌面采用左右分栏，窄屏改为上下排列，项目卡片自动调整列数 |

此外，页面提供键盘焦点样式和状态提示，适配系统“减少动态效果”设置；关闭 JavaScript 后，仍可阅读主要正文和三个未来方向的内容。

复制邮箱优先使用安全上下文中的 Clipboard API，并提供复制降级和超时反馈。开场记忆仅保存在浏览器当前会话中，不会上传到服务器。

## 八、线上部署方式

1. 将完整项目上传到自己的 GitHub 仓库。
2. 在仓库的 `Settings → Pages` 中，将发布来源设置为 `GitHub Actions`。
3. 推送到 `main` 分支会触发 `.github/workflows/static.yml`；也可以在 Actions 中手动运行该工作流。
4. 工作流发布 `docs` 目录。部署成功后，通过上方作品线上地址访问。
